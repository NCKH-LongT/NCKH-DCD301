# Paper 01 Summary

## Citation

- **Paper Title:** Accuracy recovery: A decomposition procedure for the synthesis of partially-specified Boolean functions
- **Authors:** Andrea Costamagna, Giovanni De Micheli
- **Year:** 2023
- **Journal:** INTEGRATION, the VLSI Journal (Elsevier)
- **DOI/Link:** https://www.sciencedirect.com/science/article/pii/S0167926022001791

## Problem

Logic Synthesis From Partial Specifications (LSFPS) struggles to synthesize accurate and hardware-friendly logic circuits when dealing with missing data ("don't knows"). Existing Approximate Logic Synthesis (ALS) tools often sacrifice test accuracy to achieve smaller circuit sizes, making them unsuitable for exact logic functional requirements and hardware-friendly machine learning models.

## Method

The authors propose a **Don't Knows-Aware Disjoint Support Decomposition (DK-DSD)** algorithm combined with a novel technique called **Accuracy Recovery**. The decomposition strategy uses mutual information (from Information Theory) to systematically select variables and build Boolean networks. The "Accuracy Recovery" step then maps the approximate logic circuits into a completely new topology that ensures functional accuracy on the provided specifications without expanding the hardware unnecessarily.

## Dataset

The methodology was tested on the **IWLS2020 benchmarks**, comprising 100 single-output Boolean functions from Arithmetic, Random Logic, and Machine Learning domains (ranging from 16 to 768 inputs). It was also evaluated on the **binary MNIST classification dataset**.

## Evaluation

The proposed algorithms were evaluated using the following metrics:
- **Test Accuracy:** The generalization ability on unseen data.
- **Hardware Size:** Total number of logic gates.
- **Circuit Depth:** The number of logic levels (which affects delay).
- **Runtime:** Computational synthesis speed.

## Results

Integrating the DK-DSD decomposition reduced the total number of gates by 17.38% and the circuit depth by 12.02%, while increasing test accuracy by 1.11% on average. Furthermore, applying the Accuracy Recovery technique to XAGs (Xor-And-Inverter graphs) achieved a 95.73% test accuracy on the binary MNIST dataset, outperforming the previous ALS state-of-the-art (92.76%).

## Limitations

The DK-DSD algorithm suffers from high computational complexity ($O(n^2N)$) because it dynamically explores and computes the probability mass function for variable pairs during synthesis, making the pure bottom-up decomposition step slow for extremely large datasets. Furthermore, the method relies heavily on the quality of the initial approximate circuit generated by external ALS algorithms (like MUESLI).

## Relevance to our topic

This paper is highly relevant to our **RQ-02** and **RQ2.2**. It provides a mathematical framework (Boolean decomposition using mutual information) for systematically partitioning input variables and mapping Boolean logic. The concept of utilizing a decomposition procedure to reduce gate count directly supports our proposed Decoder-OR architecture, where we aim to decompose Boolean equations accurately to avoid redundant hardware routing.

## Possible improvement

Our project can adapt the theoretical decomposition concept into a more hardware-centric approach. Instead of synthesizing random gate topologies (like AIGs or XAGs as done in the paper), we can apply these decomposition algorithms to segment inputs into discrete blocks. These blocks can then be routed systematically into standardized hardware Decoders and OR gates, yielding a machine-readable JSON schema that bypasses the computational bottleneck of searching for arbitrary gate nodes.
