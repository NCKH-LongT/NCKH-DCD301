# Topic Proposal: Firefly-Optimized CNN-LSTM for Remaining Useful Life Prediction of Rolling Bearings

## 1. Project Title
* **English:** Firefly-Optimized CNN-LSTM for Remaining Useful Life Prediction of Rolling Bearings

## 2. Project Description & Specific Domain
* **Application Domain:** This project focuses on developing an intelligent prognostics and predictive maintenance system for rolling bearings using deep learning and metaheuristic optimization techniques. The system aims to predict the Remaining Useful Life (RUL) of bearings based on run-to-failure sensor data, helping reduce unexpected machine downtime and maintenance costs.
* **Operational Model:** The proposed framework operates through a four-stage workflow:
  1. Data Collection & Preprocessing.
  2. Feature Extraction using CNN.
  3. Temporal Degradation Modeling using LSTM.
  4. Hyperparameter Optimization using Firefly Algorithm and RUL Prediction.
