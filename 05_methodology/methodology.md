# Methodology

## 1. Overview of the Proposed Framework

This study proposes a Firefly-Optimized CNN-LSTM framework for Remaining Useful Life (RUL) prediction of rolling bearings. The proposed methodology integrates deep learning and swarm intelligence optimization to improve prediction accuracy and reduce manual hyperparameter tuning.

The framework consists of five major stages:

1. Data Acquisition
2. Data Preprocessing
3. Feature Extraction using CNN
4. Temporal Degradation Modeling using LSTM
5. Hyperparameter Optimization using Firefly Algorithm

The overall workflow begins with collecting vibration signals from bearing run-to-failure datasets. The raw signals are preprocessed and transformed into sequential samples suitable for deep learning models. CNN layers automatically extract degradation-related features, while LSTM layers learn temporal degradation trends and estimate the Remaining Useful Life. To improve prediction performance, the Firefly Algorithm is employed to automatically search for optimal CNN-LSTM hyperparameter configurations.

The final output of the framework is an estimated RUL value representing the remaining operational lifetime of a bearing before failure.

---

# 2. Data Preprocessing

Data preprocessing is a critical stage in bearing prognostics because raw vibration signals often contain noise, scale variations, and redundant information that may negatively affect model performance.

## 2.1 Signal Normalization

To ensure numerical stability during model training, vibration signals are normalized before being fed into the neural network.

Normalization provides the following benefits:

* Reduces scale differences between samples.
* Accelerates model convergence.
* Improves optimization stability.
* Prevents gradient explosion and vanishing problems.

Depending on dataset characteristics, Min-Max Scaling or Z-score Normalization may be applied.

## 2.2 Sliding Window Segmentation

Bearing degradation data are continuous time-series signals. To transform the signals into learning samples, a sliding window strategy is employed.

Each window contains a fixed number of observations representing a local degradation state of the bearing.

The sliding window approach offers several advantages:

* Increases training sample size.
* Preserves temporal information.
* Enables sequence-based learning.

## 2.3 Sequence Generation

After segmentation, consecutive windows are organized into sequential inputs suitable for LSTM learning.

Each generated sequence represents the historical degradation behavior of the bearing and serves as input for RUL prediction.

# 3. CNN Module for Feature Extraction

## 3.1 Motivation

Convolutional Neural Networks (CNNs) have demonstrated strong capabilities in automatically extracting representative features from vibration signals without requiring handcrafted feature engineering.

In bearing prognostics, degradation information is often embedded within complex vibration patterns. CNN layers can effectively identify local degradation characteristics and transform raw signals into high-level feature representations.

## 3.2 CNN Architecture

The CNN module consists of:

* Convolution Layers
* Activation Functions
* Pooling Layers

The convolution operation extracts local degradation patterns from vibration sequences.

Activation functions introduce non-linearity, enabling the network to learn complex relationships within bearing degradation data.

Pooling layers reduce dimensionality and improve robustness against noise.

## 3.3 CNN Output

The output of the CNN module is a compact feature vector containing degradation-related information.

These extracted features are subsequently passed to the LSTM module for temporal learning.

---

# 4. LSTM Module for Temporal Degradation Learning

## 4.1 Motivation

Remaining Useful Life prediction is fundamentally a time-series forecasting problem because bearing degradation evolves progressively over time.

Traditional neural networks struggle to capture long-term temporal dependencies. Long Short-Term Memory (LSTM) networks are specifically designed to address this limitation.

## 4.2 LSTM Architecture

The LSTM module receives feature vectors generated by the CNN module and learns degradation evolution patterns.

The network contains three fundamental gates:

### Forget Gate

Determines which historical information should be discarded.

### Input Gate

Determines which new information should be stored in memory.

### Output Gate

Controls which information contributes to the final prediction.

These gates enable the network to effectively learn long-term degradation behavior.

## 4.3 RUL Prediction

After temporal learning, the final hidden state of the LSTM network is passed through fully connected layers to generate the predicted Remaining Useful Life value.

# 5. Firefly Algorithm

## 5.1 Biological Inspiration

The Firefly Algorithm (FA) is a swarm intelligence optimization technique inspired by the flashing behavior of fireflies in nature.

Fireflies communicate and attract one another through bioluminescent signals. A firefly with stronger brightness attracts neighboring fireflies, causing the population to gradually move toward better solutions.

This collective behavior can be adapted to solve optimization problems.

## 5.2 Brightness Concept

In the proposed framework, each firefly represents a candidate CNN-LSTM hyperparameter configuration.

The brightness of a firefly is determined by the prediction performance of the corresponding CNN-LSTM model.

Lower prediction error indicates higher brightness.

Therefore:

* Lower RMSE → Brighter Firefly
* Higher RMSE → Dimmer Firefly

## 5.3 Distance Between Fireflies

The similarity between two candidate solutions is measured using Euclidean distance.

A smaller distance indicates more similar hyperparameter configurations.

Distance information influences attraction strength and movement behavior.

## 5.4 Attractiveness

The attractiveness between fireflies decreases as distance increases.

Consequently:

* Nearby high-quality solutions exert stronger attraction.
* Distant solutions exert weaker attraction.

This mechanism balances exploration and exploitation during optimization.

## 5.5 Firefly Movement

A less attractive firefly moves toward a brighter firefly during each optimization iteration.

This movement allows the population to gradually concentrate around promising regions of the search space while maintaining diversity through random exploration.

# 6. Firefly-Based Hyperparameter Optimization

## 6.1 Optimization Objective

The primary objective of the Firefly Algorithm is to automatically identify the optimal hyperparameter configuration for the CNN-LSTM model.

Instead of manually tuning parameters, the optimization process searches for combinations that minimize prediction error.

## 6.2 Search Space

The Firefly Algorithm explores a predefined hyperparameter search space.

Typical parameters include:

| Hyperparameter | Search Range  |
| -------------- | ------------- |
| Learning Rate  | 0.0001 – 0.01 |
| CNN Filters    | 16 – 128      |
| Kernel Size    | 3 – 7         |
| LSTM Units     | 32 – 256      |
| Dropout Rate   | 0.1 – 0.5     |
| Batch Size     | 16 – 128      |

Each firefly corresponds to one candidate solution within this search space.

## 6.3 Fitness Function

The fitness value evaluates the quality of a candidate solution.

In this study, Root Mean Square Error (RMSE) is selected as the primary optimization objective.

A lower RMSE value indicates better prediction performance and therefore higher firefly brightness.

## 6.4 Optimization Procedure

The Firefly optimization process follows these steps:

1. Initialize a population of fireflies.
2. Generate random CNN-LSTM hyperparameter configurations.
3. Train CNN-LSTM using each configuration.
4. Compute RMSE values.
5. Evaluate firefly brightness.
6. Move weaker fireflies toward brighter fireflies.
7. Generate updated solutions.
8. Repeat until convergence or maximum iterations.
9. Select the best hyperparameter configuration.

# 7. Proposed Firefly-CNN-LSTM Workflow

The complete workflow of the proposed framework is summarized below:

1. Acquire bearing vibration data.
2. Normalize vibration signals.
3. Generate sliding-window sequences.
4. Extract degradation features using CNN.
5. Learn temporal degradation patterns using LSTM.
6. Predict Remaining Useful Life.
7. Evaluate prediction error using RMSE.
8. Optimize CNN-LSTM hyperparameters using Firefly Algorithm.
9. Retrain the optimized model.
10. Generate final RUL predictions.

This process combines deep feature learning and intelligent optimization into a unified prognostic framework.

# 9. Methodology Summary

This study proposes a Firefly-Optimized CNN-LSTM framework for Remaining Useful Life prediction of rolling bearings.

CNN is utilized for automatic degradation feature extraction, LSTM is employed for temporal degradation modeling, and the Firefly Algorithm serves as the optimization engine responsible for identifying optimal hyperparameter configurations.

By integrating deep learning and swarm intelligence optimization, the proposed framework aims to achieve higher prediction accuracy, lower prediction error, and improved robustness compared with conventional CNN-LSTM approaches.
