# Research Questions

To address the identified problem and fill the research gap, this project is guided by one main research question and three sub-questions:

**Main Question:**
**RQ-02: How can a decoder be used in combination with OR gates to implement a logic function instead of using basic logic gates?**

**Sub-Questions:**
- **RQ2.1:** What is the mathematical and algorithmic relationship between the outputs of a Decoder and the minterms of a logic function?
- **RQ2.2:** For a given Boolean function, how do you systematically select the correct Decoder outputs to connect to the OR gate, and how can this routing be automated (e.g., via JSON schema)?
- **RQ2.3:** What are the structural and hardware advantages (e.g., transistor count, modularity, active/standby power) of implementing logic with a Decoder compared to designing with discrete AND/OR/NOT gate networks?
